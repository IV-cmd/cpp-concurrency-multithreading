Same variable, two ways to run something else
fork(): a second process
child
pid 72884
&counter 0x608c61f62194
sets it to 100
parent
pid 72883
&counter 0x608c61f62194
still reads 0
std::thread: a second thread
thread
pid 72883, tid 72885
sets counter to 100
main
pid 72883, tid 72883
reads 100
The child had the same virtual address but its own copy of the memory behind it. The thread wrote the parent's actual counter.
